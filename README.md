# Md Mahbubur Rahman — Portfolio

A professional portfolio built with Next.js for deployment on Vercel.

## Local setup

Install Node.js, then:

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Add your CV

Place your PDF at:

```text
public/cv.pdf
```

The "Download CV" button will then work automatically.

## Customize

Main content:
- `app/page.tsx`

Design:
- `app/globals.css`

Metadata:
- `app/layout.tsx`

## Deploy on Vercel

1. Create a GitHub repository.
2. Push this project.
3. Import the repository into Vercel.
4. Vercel will detect the Next.js project automatically.

Official Vercel + Next.js deployment documentation:
https://vercel.com/frameworks/nextjs
